# Armazemdonacreusa

Build a modern, elegant, and responsive link-in-bio (Linktree-style) landing page optimized for mobile devices. 

Project Name: Armazém da Dona Creusa (Vintage Kraft aesthetic)

Target Audience: Customers looking for artisanal and rustic products directly from the farm.

Design & Aesthetic Guidelines:

- Color Palette: Earthy tones inspired by kraft paper and vintage aesthetics. Use warm kraft brown background/accents (#C19A6B or similar earthy gradients), dark charcoal text (#2B2B2B) for high readability, and subtle off-white card backgrounds (#F4F0EC) with soft terracotta highlights (#C35831).

- Typography: Clean, readable sans-serif for body text paired with a retro/vintage display font for titles.

- Layout: Centered single-column layout, mobile-first design, minimalist cards with smooth hover animations, soft shadows, and rounded corners.

Structure & Content (Top to Bottom):

1. Header / Profile Section:

   - A circular profile placeholder (or rustic badge avatar) representing a rustic stamp or vintage keyhole logo.

   - Title: "Armazém da Dona Creusa"

   - Subtitle: "Produtos artesanais direto da chácara para sua casa."

2. Links Section (Interactive buttons with clear icons):

   - Button 1 (Primary Highlight): "🛒 Ver Vitrine de Produtos" -> links to the product showcase page.

   - Button 2: "📸 Acompanhe no Instagram" -> links to Instagram profile.

   - Button 3: "💬 Falar no WhatsApp" -> links to WhatsApp direct chat.

   - Button 4: "🎬 Nossos Vídeos no TikTok" -> links to TikTok profile.

3. Footer Section:

   - Discreet text: "Feito com carinho na chácara • Vintage Kraft 2026"

Behaviors:

- Make all buttons fully clickable, responsive, and styled with smooth transition effects.

- Ensure the page looks gorgeous both on mobile screens and desktop monitors.
